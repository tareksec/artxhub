## Task 1 — Rebrand and safe isolation (2026-10-28)

Changed:
- Package id `com.techvrs.cyberhome` (debug: `com.techvrs.cyberhome.debug`), so it installs
  side by side with Lawnchair (`app.lawnchair*`). Provider authorities and custom permissions
  all derive from `${applicationId}`, so there are no install conflicts.
- App name `CyberHome` / `CyberHome (Debug)`; APK named `CyberHome.<version>.github.debug.apk`.
- Placeholder adaptive launcher icon (dark, cyan HUD brackets, house glyph) incl. themed-icon layer,
  also used as the About-screen logo.
- 13 user-visible "Lawnchair" strings rebranded in English + 62 locales via generated overlay
  (`./gradlew cyberRebrandStrings`).
- `NOTICE.md`, `docs/UPSTREAM_CHANGES.md`, this file. `LICENSE.txt` kept.
- Secrets: none needed. Release signing already falls back to the debug key when
  `keystore.properties` is missing; all upstream CI steps that use secrets are guarded by
  `github.repository_owner == 'LawnchairLauncher'` and are skipped on our fork.

Known issues / left for later:
- **License:** upstream `15-dev` is **Apache 2.0**, not GPL v3 as CLAUDE.md assumed.
  Decision (2026-10-28): keep GPL v3 for our own code and the combined app
  (GPL-3.0-or-later, text in `COPYING`); upstream `LICENSE.txt` stays. See `NOTICE.md`.
- About screen still shows Lawnchair links/contributors and fetches data from the GitHub API
  (network call, conflicts with privacy rule 6) → replace in Task 10.
- `search_provider_sponsored_description` intentionally not rebranded (it claims a revenue
  share with Lawnchair); sponsored search providers should be removed later.
- Internal names (classes `app.lawnchair.*`, theme names, log tags) unchanged on purpose.
- `baseline-profile` module still targets package `app.lawnchair` (only used to generate
  baseline profiles; not part of the APK).
- Not yet tested on a device (no device/emulator connected).

## Task 2 — Design system and wallpaper (2026-10-28)

Changed:
- Tokens (PROJECT_SPEC.md §2) in `cyber/res/values/`: `cyber_colors.xml` (bg, dot, surface,
  border, 4 accents, text, dim), `cyber_dimens.xml` (dot grid, border, 4dp radius, 8dp chamfer,
  brackets, paddings, text sizes), `cyber_styles.xml` (`Cyber.TextAppearance.Clock/Number/Title/Body/Label`).
- Fonts (SIL OFL, licenses in `docs/licenses/`): Orbitron Bold/Black (`@font/cyber_font_display`)
  for big digits/titles, Share Tech Mono (`@font/cyber_share_tech_mono`) for labels.
- Wallpapers 1440x3120 and 1080x2400 in `cyber/res/drawable-nodpi/`, generated by
  `./gradlew cyberWallpapers` (#0B0C0F, 5dp dot grid, ~6% white dots, 0.75dp radius).
- Compose side in `com.techvrs.cyberhome.cyber.design`: `CyberFonts`, `CyberTextStyles`,
  `CyberChamferShape`, `Modifier.cyberFrame(accent)` (chamfered 1dp border + accent corner
  brackets), `Modifier.cyberDotGrid()`.
- Test screen (debug builds only): `CyberDesignPreviewActivity`, shown in the app drawer as
  **"CyberHome Design"**. Renders wallpaper, blue phone card, block clock (live time, slash
  ornament, divider, date), small tiles, pink day counter, swatches, type samples, live dot grid.
- Settings/drawer theme (cheap): dark theme by default; default accent cyan `#36D1DC` (Material
  You palette is derived from it, so Settings gets dark surfaces with cyan accents); drawer
  background `#0B0C0F`, folder background `#15171C`. Users can still change all of these.

Screenshot plan (when a device is available):

   (`adb exec-out screencap -p > design.png`), check fonts render (not Roboto fallback),
   chamfers/brackets are crisp, slash crosses the hour digits.

   compare dot density with the reference; tune `cyber_dot_spacing` if needed.

Known issues / left for later:
- Theme defaults only apply to fresh installs (existing preferences are kept).
- Wallpaper is not applied automatically yet (Task 8 "Apply Look").
- `textFontWeight` in XML styles needs API 28+; on API 26–27 the family's bold face is used.
- Not tested on a device yet.
