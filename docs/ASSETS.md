# ASSETS.md — art, fonts, icons

## Rule
Do not use the anime characters, logos, or UI art from the reference screenshot or any
copyrighted source. The look (cozy anime widgets, big clock, character cards) is the inspiration;
the **art must be original, licensed, or generated by the owner**.

## What is needed

| Asset | Spec | Source for v1 |
|---|---|---|
| Character card art x3 | Portrait ~ 600x800 px PNG/WebP, soft pastel background, keep the lower third calm (captions fade over it) | Placeholders: simple original vector silhouettes/abstract art made by Claude Code (SVG -> PNG). Owner replaces with own/licensed art later. |
| Wallpaper | 1440x3120 px (also 1080x2400), light (cream) and dark (plum-charcoal) versions with soft pastel blobs | Generated by script (no copyrighted content) |
| Launcher icon | Adaptive icon (foreground 108dp) | Simple original placeholder |
| Icons (rounded line, 2dp stroke) | Phone, Message, Settings, Calendar, Cloud, Lightning, Music prev/next/play, Drop (water), Gamepad, Camera, App-drawer dial | Vector drawables (Material Symbols, Apache 2.0, or drawn by hand). Keep credits in NOTICE.md |
| Widget previews | One preview PNG per widget | Screenshot after each widget is finished |
| Font | Soft rounded family for digits and labels | Open license only (SIL OFL / Apache). Chosen: **Nunito** (OFL). Bundle the font file and its license text. |

## Folder layout
```
assets-proprietary/     <- owner's original art, license: All rights reserved (own LICENSE file)
  cards/
  wallpapers/
  icons-brand/
app/src/main/res/font/  <- OFL/Apache fonts + their license files in docs/licenses/
docs/licenses/
```

## Art later (owner's task)
- Make or commission original characters, or generate with an AI tool whose terms allow commercial use, and keep the proof of license.
- Keep the source files (PSD/PNG) outside the public git repo if you plan to sell them as premium theme packs.
- Premium packs idea: deliver extra card art/themes as downloadable content after purchase, not inside the public source.
